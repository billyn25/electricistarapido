# Portada reorganizada: 20 de octubre de 2026

Orden publicado por el generador: presentación y contacto, cinco accesos por avería, diez tarjetas de servicio, directorio de síntomas, cobertura compacta de las cinco provincias, formulario de consulta, proceso de diagnóstico, banda de atención y directorio completo de localidades.

Se fusiona la lista breve de servicios con las tarjetas desarrolladas, se eliminan el segundo bloque de ejemplos genéricos, las estrellas decorativas y el resumen duplicado de localidades. Se mantienen los 533 enlaces municipales y sus desplegables, las diez guías y los ejemplos de avería. El formulario utiliza el selector regional existente para dirigir Madrid y zona norte a sus teléfonos correspondientes.

Validación local: npm run build:release (40 pruebas), auditoría de 573 páginas, ausencia de títulos duplicados, enlaces y anclas válidos, schema JSON válido, canonical y robots conservados; auditoría adicional del orden, ID únicos y 533 enlaces municipales de portada.
